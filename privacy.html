01 ・ Scope

この説明の対象

公開サイト「発走前ラボ」と、運営者が自分のチャンネルの数字を集計するために使うアプリ「hassomae_api」が対象です。買い目や成績を見るのに、会員登録やログインは要りません。

02 ・ Google data

YouTube のデータの扱い

  • hassomae_api は、運営者が自分の Google アカウントでログインして許可した、運営者自身の YouTube チャンネルのデータだけを読みます。ほかの人のアカウントのデータは取得しません。
  • 読むのは、チャンネルと動画の基本情報、再生数・登録者数などの統計です(読み取りの権限 youtube.readonly と yt-analytics.readonly)。
  • 運営者が自分で作った動画(競馬教室のショート)を、運営者自身のチャンネルへ予約投稿し、運営者自身の再生リストに入れるために、アップロードと管理の権限(youtube.upload と youtube)も使います。ほかの人の動画やチャンネルには触れません。コメントの書き込み・動画の削除はしません。
  • 取得した数字は、運営者の収益と運用の状況を確かめるために、運営者の個人用の集計画面で使います。
  • ログインの情報と取得した数字は、運営者のパソコンの中に保存します。第三者に渡したり、売ったり、広告に使ったりはしません。
  • Google の API から受け取った情報の利用と移転は、Google API サービスのユーザーデータに関するポリシー(Limited Use の要件を含む)に従います。
  • 許可は Google アカウントのサードパーティ接続の画面からいつでも取り消せます。取り消した場合、運営者は保存した情報を削除します。
03 ・ Other services

ほかのサービスの数字

TikTok などのほかのサービスも、運営者自身のアカウントの数字だけを同じ目的で読み、同じように扱います。

04 ・ Site

このサイトの計測

このサイトは、Cookie を使わない計測サービス GoatCounter で、見られたページ・どのサイトから来たか・ボタンが押された回数(note へのリンクや、本命の診断で判定が出た回数など)の集計だけを見ています。本命の診断に入れた馬やオッズは、どこにも送りません。個人を特定する目的では使いません。リンク先の X・note・YouTube では、それぞれのサービスの決まりが適用されます。
